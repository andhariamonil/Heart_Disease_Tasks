# Heart Disease Prediction Using Machine Learning

## Task 51: Manual Neural-Network Learning-Rate Scheduler

### Objective

Compare a constant learning rate with a hand-written reduce-on-validation-plateau scheduler for the scratch MLP. Record per-epoch learning rate, training/validation loss, cumulative parameter-update norm, and held-out metrics. No built-in scheduler is used.

### Run

From the `Heart_Disease_Tasks` directory:

```bash
source .venv/bin/activate
streamlit run Task_51_Manual_Neural_Learning_Rate_Scheduler/app.py
```

Run all cells in `Task_51_Manual_Neural_Learning_Rate_Scheduler/Task_51_Manual_Neural_Learning_Rate_Scheduler.ipynb` for the standalone notebook.
