# Heart Disease Prediction Using Machine Learning

## Task 76: Accessible Custom-CSS Dashboard

### Objective

Build an interactive review screen using custom CSS and HTML-rendered components, responsive CSS grid rules, keyboard-visible focus states, high-contrast colors, hover transitions, and reduced-motion support. Model and case selection remain interactive through Streamlit controls.

The interface presents model associations only and labels the experience as educational, not diagnostic.

### Run

From the `Heart_Disease_Tasks` directory:

```bash
source .venv/bin/activate
streamlit run Task_76_Accessible_Custom_CSS_Dashboard/app.py
```

Run all cells in `Task_76_Accessible_Custom_CSS_Dashboard/Task_76_Accessible_Custom_CSS_Dashboard.ipynb` for the standalone notebook.
