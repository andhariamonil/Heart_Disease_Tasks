# Heart Disease Prediction Using Machine Learning

## Task 37: k-NN Elbow Method

### Objective

Compare odd `k` values using manually implemented nearest-neighbor search and stratified 5-fold validation on unique records, preventing identical rows from leaking across folds. Plot fold-mean error rates and standard errors with Matplotlib, then select the smallest `k` within one standard error of the minimum mean error.
