# Heart Disease Prediction Using Machine Learning

## Task 59: Misclassification and Cluster Analysis

### Objective

Manually cluster false-positive and false-negative cases with k-means, flag unusual feature values relative to training statistics, inspect error examples, and summarize both counts and denominator-normalized FPR/FNR across sex and age bands.

Clusters and subgroup rates are exploratory; small samples and measurement quality can create misleading patterns. Review individual cases and obtain domain oversight before acting on them.
