# Heart Disease Prediction Using Machine Learning

## Task 35: Polynomial and RBF Kernel SVM

### Objective

Build polynomial and RBF kernel matrices from their mathematical definitions, train kernelized SVMs with manual SMO updates, and compare held-out performance and support-vector distributions by class. Duplicate records are removed before splitting to prevent train/test leakage.

### Run

From the `Heart_Disease_Tasks` directory, activate the project environment and run:

```bash
streamlit run Task_35_Kernel_SVM_From_Scratch/app.py
```

Open `Task_35_Kernel_SVM_From_Scratch/Task_35_Kernel_SVM_From_Scratch.ipynb` and run all cells to use the notebook version.
