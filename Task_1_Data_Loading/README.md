# Heart Disease Prediction Using Machine Learning

## Task 1: Dataset Loading, Pagination and Sorting

### Objective
Load the Heart Disease dataset in a Streamlit application without using Pandas. The dataset is manually parsed, displayed, sorted, and paginated.

### Requirements Implemented
- Manual CSV file loading
- Manual delimiter detection
- No Pandas used for dataset loading
- Dataset display in Streamlit
- Sorting functionality
- Pagination functionality

### Files
- app.py
- heart.csv
- requirements.txt

### Run

```bash
streamlit run app.py
