# Heart Disease Prediction Using Machine Learning

## Task 41: Deep Learning vs Traditional Machine Learning

### Objective

Compare scratch logistic regression, decision tree, random forest, and a manually trained neural network. Compute accuracy, precision, recall, and F1 from predictions, compare train/test gaps for overfitting, and discuss model complexity, explainability, data requirements, and practical trade-offs.

Duplicate records are removed before the stratified split. Scaling statistics are fit on training data only. The comparison is educational and is not intended for diagnosis.

### Run

From the `Heart_Disease_Tasks` directory:

```bash
source .venv/bin/activate
streamlit run Task_41_Deep_Learning_vs_Traditional_ML/app.py
```

Run all cells in `Task_41_Deep_Learning_vs_Traditional_ML/Task_41_Deep_Learning_vs_Traditional_ML.ipynb` for the standalone notebook.
