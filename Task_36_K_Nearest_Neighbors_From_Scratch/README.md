# Heart Disease Prediction Using Machine Learning

## Task 36: k-Nearest Neighbors From Scratch

### Objective

Calculate Euclidean distances manually, search a balanced KD-tree with bounding-box pruning, and classify with deterministic tie handling. Duplicate records are removed before the held-out split to avoid train/test leakage; the selected `k` is configurable in the app.

### Run

From the `Heart_Disease_Tasks` directory, activate the project environment and run:

```bash
streamlit run Task_36_K_Nearest_Neighbors_From_Scratch/app.py
```

Open `Task_36_K_Nearest_Neighbors_From_Scratch/Task_36_K_Nearest_Neighbors_From_Scratch.ipynb` and run all cells to use the notebook version.
