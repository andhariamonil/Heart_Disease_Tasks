# Heart Disease Prediction Using Machine Learning

## Task 5: Numerical Data Visualization

### Objective

Visualize the distribution of numerical columns using raw Matplotlib commands with custom aesthetics, annotations, and comparative plots.

### Requirements Implemented

- Distribution plots for numerical columns
- Matplotlib histograms
- Custom titles and labels
- Grid and transparency for better visualization
- Plot annotations
- Comparative histogram
- Comparative box plot

### Numerical Columns

The following numerical columns are visualized:

- age
- trestbps
- chol
- thalach
- oldpeak
- ca

### Implementation

The visualizations are created using Matplotlib directly.

No Seaborn plotting functions are used.
