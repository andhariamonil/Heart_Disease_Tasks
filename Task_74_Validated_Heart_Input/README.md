# Heart Disease Prediction Using Machine Learning

## Task 74: Validated Heart-Feature Input

### Objective

Validate required numeric values, finiteness, categorical codes, broad plausible ranges, and training-distribution ranges. Return contextual messages and deterministic suggestions; apply them only to a temporary copy after explicit user approval. Invalid inputs never reach the model.

The app's limits and category codes come from the supplied data schema and are not clinical reference ranges.

### Run

From the `Heart_Disease_Tasks` directory:

```bash
source .venv/bin/activate
streamlit run Task_74_Validated_Heart_Input/app.py
```

Run all cells in `Task_74_Validated_Heart_Input/Task_74_Validated_Heart_Input.ipynb` for the standalone notebook.
