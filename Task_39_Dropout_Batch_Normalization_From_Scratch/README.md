# Heart Disease Prediction Using Machine Learning

## Task 39: Dropout and Batch Normalization From Scratch

### Objective

Train a small neural network without built-in layers. Apply inverted dropout masks and manually derive batch-normalization forward/backward updates for gamma and beta, maintain running activation statistics, and compare the regularized network with a plain baseline.

### Run

From the `Heart_Disease_Tasks` directory:

```bash
source .venv/bin/activate
streamlit run Task_39_Dropout_Batch_Normalization_From_Scratch/app.py
```

Run all cells in `Task_39_Dropout_Batch_Normalization_From_Scratch/Task_39_Dropout_Batch_Normalization_From_Scratch.ipynb` for the standalone notebook.
